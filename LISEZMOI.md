# Site vitrine — Atelier

Site statique, prêt à être ouvert dans Claude Code puis publié.
Les instructions détaillées du projet sont dans **CLAUDE.md** (Claude Code les lit automatiquement).

## Démarrer dans Claude Code
1. Dézippez ce dossier là où vous rangez vos projets.
2. Ouvrez-le dans Claude Code.
3. Collez le message de démarrage (fourni dans la conversation) : Claude Code complète
   les textes, crée le dépôt GitHub et vous guide pour relier l'hébergeur.

## Au quotidien
- Ajouter un meuble : déposez les photos brutes dans `photos-brutes/` et demandez à Claude Code
  « ajoute ce meuble : titre …, matériaux …, couverture … ».
- Voir le site avant de publier : « lance l'aperçu local ».
- Publier : « publie les modifications » (envoi sur GitHub → mise en ligne automatique).
